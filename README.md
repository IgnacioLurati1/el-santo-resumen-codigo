# El Santo Resumen

Resúmenes, quizzes y herramientas de estudio de Ingeniería en Sistemas de la UTN Rosario. El sitio oficial es uno solo:
**https://lutastudios.com/utn/**. Este es su código, para que cualquiera lo revise.

## Probarlo

```
npm install
npm run build
```

Deja el sitio en `dist/`. Para verlo, serví esa carpeta con cualquier servidor estático.

- **Contenido:** los apuntes reales salen del Drive de la carrera y son de alumnos y docentes: no vienen en este
  repositorio. En su lugar hay una materia inventada, `fuente/materia-de-ejemplo/`. Para sumar una, copiala y agregala
  en `materias.json` y `niveles.json`.
- **Secciones generales** (plan, mesas, docentes, agradecimientos, novedades): `secciones/*.json`, con datos de ejemplo.
- **Servicio** (cuentas, estrellas, banco de resúmenes): `servicio.json` viene vacío, así el sitio se arma sin servicio.
  El servicio oficial no forma parte de este repositorio.

## Aportar

Abrí un issue o un pull request. Lo que se suma al sitio oficial se pasa a mano.
